## 🤔 Troubleshooting

Here are common issues and how to fix them:

- **The app won’t open:**  
   Check your system matches the requirements. Try restarting your computer. If using Windows, run as Administrator by right-clicking the app icon.

- **Posts fail to send:**  
   Verify your internet connection. Make sure your forum passwords are correct in the app.

- **Login denied errors:**  
   Some forums may ask for extra verification like captchas. exforum-auto-poster cannot bypass these. Check your forum’s security settings.

- **App crashes:**  
   Close other programs and try again. If problem persists, reinstall the app from the download page.

For help, you can also check the app’s log files located in the program folder.
